# Vault

Personal knowledge vault for Jivesh, operated by Claude Code via [`CLAUDE.md`](CLAUDE.md).

## Folders

- `daily/` — daily notes, one file per day (`YYYY-MM-DD.md`)
- `people/` — one file per person (`firstname-lastname.md`)
- `projects/` — active projects (`slug.md`)
- `goals/` — long-running goals and OKRs (`slug.md`)
- `journal/` — monthly reflective journal (`YYYY-MM.md`)
- `todos.md` — global inbox for loose todos without a clear project home
- `README.md` — this index

## Usage

Run `claude` from this folder; it reads `CLAUDE.md` automatically.
